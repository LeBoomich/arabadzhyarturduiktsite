Лабораторна робота №4

Контрольні запитання та відповіді

1. Що таке CSS і яка його роль у веб-розробці?
CSS - це мова стилів, яка використовується для оформлення вебсторінок. За допомогою неї можна змінювати кольори, шрифти, розміри та розташування елементів.

2. Які основні властивості в CSS і як вони задаються?
Основні властивості CSS відповідають за кольори, фон, шрифти, розміри та відступи. Вони задаються у вигляді назви властивості та її значення.

3. Що таке селектори в CSS? Наведіть приклади різних типів селекторів.
Селектори - це елементи, за допомогою яких ми вибираємо, до чого застосовувати стилі. Основні типи: селектор тегу, класу, ідентифікатора та універсальний селектор.

4. Яка різниця між класовим та ідентифікаторним селекторами?
Клас можна використовувати для декількох елементів, а ідентифікатор повинен бути унікальним на сторінці. Клас позначається крапкою, а ідентифікатор решіткою.

5. Як записати коментарі в CSS?
Коментарі записуються між спеціальними символами. Вони використовуються для пояснення коду та не впливають на роботу сторінки.

6. Як змінити фоновий колір, колір тексту та розмір шрифту для елементу?
Для цього використовуються властивості background-color, color та font-size відповідно.

7. Як задати межі (borders), відступи (margins) та внутрішні відступи (padding) для елементів в CSS?
Для меж використовується border, для зовнішніх відступів margin, а для внутрішніх padding. Вони допомагають налаштувати вигляд і розташування елементів.
